# Python Practice - Ethan Tech

This repository contains beginner-friendly Python practice notebooks focused on core programming concepts. It is designed to help learners strengthen their understanding of Python through hands-on examples and simple exercises.

## Overview

The repository includes practice materials for the following fundamental topics:

- Loops
- Operators
- Strings

These notebooks are ideal for students, beginners, and anyone looking to revise Python basics in a practical way.

##1. Loops
The Loops folder contains practice exercises on iteration in Python.

Topics covered:
Basic for loops using range()
Nested for loops
Comparing values in multiple lists
Simple conditional logic inside loops
Example concepts:
Printing numbers from 1 to 4
Finding matching values between two lists
Checking for common values across three lists
This section helps learners understand how loops work and how they can be used to process repeated tasks efficiently.

##2. Operators
The Operators folder includes examples for all major types of Python operators.

Topics covered:
Arithmetic operators
Comparison operators
Logical operators
Assignment operators
Bitwise operators
Identity operators
Membership operators
Example concepts:
Addition, subtraction, multiplication, division
Greater than, less than, equality checks
and, or, and not
+=, -=, *=, /=, etc.
Bitwise AND, OR, XOR, and shift operations
Checking object identity and membership in sequences
This section is essential for understanding how Python evaluates expressions and conditions.

##3. String
The String folder focuses on string handling and basic text operations.

Topics covered:
String slicing
Searching for words or phrases inside a string
Escape sequences
Basic string output and formatting
Example concepts:
Extracting characters from a sentence
Checking if a word exists in a string
Using special characters like newline and tab
Printing text with proper escaping
This section helps beginners understand how strings are manipulated in Python.
