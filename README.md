# Python Practice - Ethan Tech

This repository contains beginner-friendly Python practice notebooks focused on core programming concepts. It is designed to help learners strengthen their understanding of Python through hands-on examples and simple exercises.

## Overview

The repository includes practice materials for the following fundamental topics:

- Loops
- Operators
- Strings

These notebooks are ideal for students, beginners, and anyone looking to revise Python basics in a practical way.
